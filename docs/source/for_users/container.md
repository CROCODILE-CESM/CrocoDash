# Running in a Container

[crocontainer](https://github.com/CROCODILE-CESM/crocontainer) is a development and
testing container for CrocoDash. It can build and run a CrocoDash case in CESM on a laptop
(Podman or Docker) or on Derecho (Apptainer), without a CESM machine port or a batch queue.

It changes often and assumes you know your way around CESM and CIME, so it's a tool for
experienced users and not part of the standard CrocoDash workflow. To use it, follow
crocontainer's [README](https://github.com/CROCODILE-CESM/crocontainer#readme).
